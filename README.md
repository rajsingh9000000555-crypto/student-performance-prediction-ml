# Student Performance Prediction (ML Project)

A modular, end-to-end demonstration predicting a student's final score (regression) and underperformance risk (classification), with a Streamlit interface.


## Important dataset note
`data/raw/student_data.csv` is **synthetic** and generated by `src/generate_data.py`. Its model metrics are only a software demonstration. Replace it with ethically collected, anonymized real data and validate before making any decisions about students.

## Setup
Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/generate_data.py
python src/train.py
streamlit run app/dashboard.py
```

## Project capabilities
- Synthetic dataset generator
- Train/test evaluation with MAE, RMSE, R²
- Regression model benchmarking (Random Forest, HistGradientBoosting)
- Underperformance risk classifier (score threshold demo: <50)
- Saved pipelines in `models/`
- Metrics in `reports/model_metrics.json`
- Interactive dashboard for prediction

## Inputs
Study hours, attendance, previous score, assignment score, sleep, extracurricular participation, internet access, parental education, family support.

## Responsible use
Risk flags should be used to offer support, not punish or label students. Check model errors across groups, avoid sensitive proxies where possible, use transparent thresholds, and obtain institutional approval for real data.
