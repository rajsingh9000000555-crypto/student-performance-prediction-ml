# Student Performance Prediction

A machine learning project designed to predict student academic performance and identify potential academic risks based on academic and behavioral factors.

## Features
- Final score prediction
- Academic risk classification
- Interactive Streamlit dashboard
- Model evaluation and performance metrics
- Feature importance analysis

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Streamlit, Joblib

## Project Structure
- `app/` – Dashboard application
- `src/` – Data generation and model training
- `data/` – Dataset
- `models/` – Trained models
- `reports/` – Evaluation results and artifacts
- `logs/` – Application and training logs

## Installation and Usage

```bash
git clone https://github.com/rajsingh9000000555-crypto/student-performance-prediction-ml.git
cd student-performance-prediction-ml
pip install -r requirements.txt
python src/generate_data.py
python src/train.py
streamlit run app/dashboard.py
```
